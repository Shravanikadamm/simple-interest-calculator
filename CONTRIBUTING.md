
# Contributing Guidelines

We welcome all contributions to this project.

## All Contributions
All contributions are welcome, including bug reports, bug fixes, documentation improvements, enhancements, and new ideas.

## Bug Reports
Please describe the issue clearly and provide steps to reproduce it.

## Bug Fixes
You can submit fixes for existing bugs through pull requests.

## Documentation Improvements
You can help improve the README and other project documentation.

## Enhancements
Suggestions and improvements to the simple interest calculator are welcome.

## New Ideas
Feel free to share ideas that can improve the project.

## Pull Requests
Please provide a clear description of your changes when submitting a pull request.

Thank you for contributing!
