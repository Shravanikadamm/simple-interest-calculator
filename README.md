# Simple Interest Calculator

## Description
This project is a simple interest calculator developed using a Bash shell script. It calculates simple interest based on the principal amount, rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Requirements
- Bash shell
- Terminal

## How to Run
1. Clone or download this repository.
2. Open the terminal.
3. Navigate to the project folder.
4. Run the following command:

```bash
bash simple-interest.sh
```

## Input
- Principal amount
- Rate of interest
- Time period

## Output
The calculated simple interest is displayed on the terminal.
